The application processes video frames in a local browser worker and sends
derived posture metadata only to the local FocusGuard API when connected.
MediaPipe's general privacy notice permits Google performance/usage metrics.
Google's June 10, 2026 clarification states that the Web SDK at that time did not
include telemetry. The pinned 0.10.32 release predates that clarification; do not
assume future SDK releases retain the same behavior. Reassess privacy and runtime
compatibility before updating the pinned version.
